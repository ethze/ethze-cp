# ethze-cp

Next.js port of the ethze landing page, including the WebGL logo.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- SCSS

## Setup

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```

The original static page is kept in `reference/index.html` for visual comparison.
